Road to Legend sound demos

Every sound the game could use, made in code so it plays offline with no audio files or licences. Press play on anything. Each sound has a code (like R4) so you can tell me which to keep, change or drop.

Nothing here is in the game yet. Once you're happy, I wire in the ones you pick and hook the volume sliders that already sit in Settings.

How it goes into the game

  1. You listen here and tell me which codes to keep, change or drop.
  2. I add one sound player to the game with the five channels above. Settings already has Master, Music, Engines, Crowd and Mute; I'd add Effects for menu and world sounds.
  3. The kept sounds go in: menus first, then the race (engines, gate drop, crashes, crowd, fireworks), then the towns, then music.
  4. Any sound can later be swapped for a recorded file dropped into the game's audio folder, with the code-made one as the fallback. Real engine recordings would sound the most like a bike, if you'd rather have those.
Sounds start only after you press a button (browsers block sound until then). Headphones help with the engines and the stereo fly-bys.
