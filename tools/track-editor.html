Track editor help

  • The drawing is the shape the race screen shows: points on a 100 × 60 grid, joined in order and back to the first point, which is the start line. Arrows show the riding direction.
  • Points: drag a point to move it (snaps to whole grid units; untick Snap or hold Alt for tenths). Double-click the track to add a point there. Right-click a point or press Del to delete it. Round corner R swaps a sharp point for a curve, like the berms on the backyard loop.
  • Sections are what the race simulation rides, in order. Each is placed on the drawing by its share of the lap length. Click the track to pick the section under the pointer. Drag a white diamond to move the boundary: metres move between the two sections and the lap stays the same length.
  • Gates is the start bonus curve, in percent of start time, best gate first (Spec 10.4). Race tracks need one; practice-only tracks can leave it empty.
  • Renaming a track's id also updates the venues that use it. A track a venue uses can't be deleted.
  • Export / Import save one track as a .track.json file and add one back, for sharing tracks and for the planned modding tools.
  • Preview P rides a dot round the lap. It spends longer in the harder sections (racing.json diff), so you can see where the lap is slow.
  • Save Ctrl+S. Undo Ctrl+Z, Redo Ctrl+Y. An unchanged file saves back byte for byte. After saving, run npm test; the game also checks tracks.json when it starts.
